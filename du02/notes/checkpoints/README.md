# Learning checkpointy ZPG

Tento adresář obsahuje datované záznamy vývoje pochopení při práci na ZPG projektu.

Doporučený název:

`YYYY-MM-DD--kratke-tema.md`

Každý checkpoint má obsahovat:

## Kontext
- řešené téma,
- relevantní chat / etapa práce,
- relevantní Git commit(y).

## Samostatně prokázáno
Co student vysvětlil, navrhl nebo implementoval bez dodání klíčové myšlenky.

## Pochopeno s vedením
Co bylo pochopeno až po nápovědě, vysvětlení nebo korekci.

## Vývoj pochopení
- původní představa,
- co nebylo jasné,
- co změnilo pohled,
- jak je princip chápán nyní.

## Potřebuje upevnit
Co ještě není stabilní nebo nebylo samostatně ověřeno.

## Další procvičení
Konkrétní budoucí úlohy nebo otázky pro ověření pochopení.

## Důkazy
Relevantní commit, diff, část kódu nebo bod z diskuse.

Pokud něco nelze spolehlivě posoudit, použij formulaci „zatím nevyhodnoceno“.
