# Poznámky k učení ZPG

- `concepts/` — obecné poznatky použitelné napříč úlohami a chaty.
- `checkpoints/` — datované záznamy vývoje pochopení.

Konkrétní checkpointy mají zachycovat nejen správný výsledek, ale také změnu mentálního modelu: co nebylo jasné, jak se to vyjasnilo a co ještě zbývá upevnit.
